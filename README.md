# B7VTI - Elektrische Grundgrößen Lernmodul
## Informationstechnische Assistenten

### 🚀 Willkommen zum interaktiven Lernmodul!

Dieses Repository enthält ein vollständiges selbstgesteuertes Lernmodul zum Thema **"Elektrische Grundgrößen in Gleich- und Wechselstromkreisen"** speziell für angehende **Informationstechnische Assistenten**.

### 📋 Inhalt

Das Modul besteht aus 10 aufeinander aufbauenden Lernschritten mit:
- 🎯 Praxisnahen Handlungssituationen aus dem IT-Bereich
- 📖 Fundiertem Fachwissen zu elektrischen Grundlagen
- 🔧 Interaktiven Tinkercad-Simulationen
- 🧮 Rechenübungen mit IT-Bezug
- ✅ Selbstüberprüfungen mit Lösungen

### 🗂️ Lernschritte

1. **[Grundlagen: Spannung und Strom](./Lernschritt_1_Grundlagen_Spannung_Strom/)**
2. **[Widerstand und Ohm'sches Gesetz](./Lernschritt_2_Widerstand_Ohmsches_Gesetz/)**
3. **[Leistungsberechnung](./Lernschritt_3_Leistungsberechnung/)**
4. **[Reihenschaltung](./Lernschritt_4_Reihenschaltung/)**
5. **[Parallelschaltung](./Lernschritt_5_Parallelschaltung/)**
6. **[Gemischte Schaltung](./Lernschritt_6_Gemischte_Schaltung/)**
7. **[Spannungsteiler](./Lernschritt_7_Spannungsteiler/)**
8. **[Brückenschaltung](./Lernschritt_8_Brueckenschaltung/)**
9. **[Spannungsversorgung - Linear- und Schaltregler](./Lernschritt_9_Spannungsversorgung/)**
10. **[Kondensatoren in Gleichstromkreisen](./Lernschritt_10_Kondensatoren/)**

### 🎯 Lernziele

Nach Abschluss dieses Moduls können Sie:
- Elektrische Grundgrößen (U, I, R, P) erklären und berechnen
- Verschiedene Schaltungsarten analysieren und dimensionieren
- Tinkercad für Schaltungssimulationen einsetzen
- Praktische IT-Probleme mit elektrischen Berechnungen lösen

### 🛠️ Benötigte Tools

- **Tinkercad** (kostenlos): https://www.tinkercad.com/
- Taschenrechner oder Computer
- Notizbuch für eigene Aufzeichnungen
